## 🗣️ User Prompt & Requirement Statement

> [!QUOTE] **Founder's Directive:**  
> "I want to create an original, high-production 2.5D deceptive platformer called **Devil's Door** ('Reach the Door. Trust Nothing.'). The game must be completely original—built from first principles without copying source code, assets, or levels from any existing platformers like Level Devil. It must feature zero external audio dependencies (instant loading), modular architecture without heavy build toolchains, and have a complete open-source enterprise governance structure."

---

## 🧠 Technical Analysis & Architectural Formulation

1. **Originality Guarantee**: Devil's Door must avoid clone tropes (e.g. basic rising door clichés). All level geometry, deception states, and visual identities must be original.
2. **Zero-Build Vanilla ESM**: Using browser-native ECMAScript Modules (`import`/`export`) allows instant hot-reloading in local development and zero dependency rot over time.
3. **Locked Documentation Bibles**: Before writing game code, establish complete formal specifications across 10 distinct domains to guide all subsequent development.
