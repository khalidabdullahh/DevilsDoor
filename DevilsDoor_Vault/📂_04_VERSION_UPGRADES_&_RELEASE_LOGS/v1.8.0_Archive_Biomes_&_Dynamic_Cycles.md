### Added
- Created 6 dynamic procedural biomes matching the 16 reference artwork scenes in `Archive/`:

  3. *Whispering Bamboo Grove*
  4. *Demonic Thorn Crypts*
  5. *Sky Waterfall Chasms*

- Dynamic weather particle emitters (cherry blossom petals, snow crystals, smoke embers, mist updrafts).
