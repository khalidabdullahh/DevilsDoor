## [0.1.0] - 2026-09-01

### Added
- Initial project architecture and complete open-source governance suite (`README.md`, `AGENTS.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `GOVERNANCE.md`, `LICENSE`).
- Comprehensive documentation specifications in `docs/` (`MASTER_CONTEXT`, `GAMEPLAY_SPEC`, `DECEPTION_ENGINE`, `MECHANICS_LIBRARY`, `VISUAL_BIBLE`, `LEVEL_DESIGN_BIBLE`, `MONETIZATION`, `ANALYTICS`, `ROADMAP`, `DECISIONS`).
- Custom 2.5D WebGL/Canvas rendering pipeline with depth lighting, soft shadows, and color family themes.
- Responsive physics engine featuring coyote time (100ms), jump buffering (120ms), and variable jump height.
- Data-driven Deception Engine (Trigger $\to$ Condition $\to$ Action $\to$ Result).
- Modular Door system supporting dynamic deception behaviors.
- Atmospheric Shadow Devil presence and interactive gaze mechanics.
- Procedural Web Audio API sound synthesizer with zero external asset dependencies.
- Cinematic 7-10s in-game intro sequence with instant skip.
- 5 handcrafted, distinct prototype levels validating the mechanics library.
- Mobile-first responsive touch controls and HUD overlay.
- Modern marketing landing website with system-aware Light/Dark themes.
- CI automated test and integrity validation suite (`scripts/test-integrity.js`).
